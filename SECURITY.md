# Security Policy

## Supported Versions

Only the latest release of `gmail_oauth_reader` receives active security updates and patches.

| Version | Supported |
| ------- | --------- |
| 1.7.x   | Yes       |
| < 1.7.0 | No        |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly.

Do not open a public GitHub issue for security vulnerabilities.

Instead, report security concerns via one of the following channels:
- **GitHub Private Vulnerability Reporting**: Use the **Report a vulnerability** button under the [Security tab](https://github.com/aaronburt/gmail_oauth_reader/security).
- **Direct Email**: Send details directly to `email@aaronburt.co.uk` with the subject line `[SECURITY] gmail_oauth_reader vulnerability report`.

### What to Include

To help triage and resolve the issue quickly, please provide:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions or proof-of-concept demonstrating the issue.
- Details of your environment (Home Assistant version, Python version, integration version).

### Response Timeline

- **Initial Response**: Within 48 hours acknowledging receipt of the report.
- **Status Updates**: Periodic updates during the investigation and remediation process.
- **Resolution & Release**: A patched release will be published once the fix is verified.
