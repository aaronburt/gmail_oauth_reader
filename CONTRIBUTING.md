# Contributing Guidelines

Thank you for considering contributing to `gmail_oauth_reader`.

## Reporting Issues

- Use GitHub Issues to submit bug reports and feature requests.
- Before opening an issue, check existing open and closed issues to avoid duplicates.
- For security vulnerabilities, refer to [SECURITY.md](SECURITY.md) and do not report vulnerabilities publicly.

## Submitting Pull Requests

1. Fork the repository and create your branch from `main`.
2. Follow existing code style (clean, descriptive naming, no redundant comments/docstrings).
3. Ensure all tests pass (`pytest`).
4. Follow Conventional Commits format for your commit messages: `type(scope): description`.
5. Open a Pull Request against `main` detailing the changes made and testing performed.
